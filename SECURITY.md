# Segurança e privacidade

Não publique credenciais nem informações privadas em Issues ou Pull Requests.

Este projeto usa serviços de terceiros e mecanismos de autorização do usuário. O código-fonte **não** deve conter sessões exportadas do Roku, API keys privadas, QR codes ativos, senhas ou dados de contas.

Para relatar uma falha de segurança, entre em contato reservadamente com o mantenedor pelo perfil do repositório; não divulgue o segredo em uma issue pública.

Se uma credencial tiver sido publicada por engano, revogue-a/rotacione-a no serviço correspondente. Apagar o arquivo em um commit posterior **não apaga o segredo do histórico Git**.
