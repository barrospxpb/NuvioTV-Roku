# Créditos e materiais de terceiros

Este projeto é uma adaptação comunitária para Roku, não uma versão oficial.

## Código-base

- **Esmequiinn — NuvioTVSmart-Roku**: https://github.com/Esmequiinn/NuvioTVSmart-Roku  
  Base principal utilizada nesta versão, identificada no pacote original como **v0.1.8 IPTV**. Licença: **GNU GPL-3.0**. O projeto inclui interface, módulos de catálogo, reprodução e IPTV.
- **NuvioMedia — NuvioTVSmart**: https://github.com/NuvioMedia/NuvioTVSmart  
  Projeto Nuvio para TVs que aparece na linhagem informada pelo repositório Roku. Licença declarada: **GNU GPL-3.0**.
- **iqui27 — Nuvio Native Legacy**: https://github.com/iqui27/nuvio-native-legacy  
  Referência de design e experiência de uso durante a adaptação. O histórico do pacote recebido **não demonstra a procedência individual de cada recurso visual**. Qualquer arquivo efetivamente copiado desse projeto precisa ter sua origem e seus avisos preservados.

## Modificações locais (snapshot Build 87)

- Tela de QR Code e seleção de perfis com personalizações gráficas.
- Integração local de componentes e versões experimentais anteriores.
- Preparação para publicação: README, documentação, checagem estática, scripts de empacotamento e remoção de uma chave fixa de fallback do YouTube.
- Omissão de dois mosaicos antigos não referenciados pelo código (`legacy_profiles_collage.jpg` e `nuvio_profiles_mosaic_user.jpg`).

O repositório contém imagens de interface e ícones derivados dos pacotes de origem. Antes de uma redistribuição ampla ou comercial, verifique a licença e a proveniência de cada arte. Em caso de dúvida, substitua-a por arte própria licenciada de forma apropriada.

O aplicativo não inclui assinaturas, tokens de usuário, listas de canais, mídias para reprodução ou direitos sobre catálogos e fontes de terceiros.
