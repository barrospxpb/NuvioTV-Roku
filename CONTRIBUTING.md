# Contribuindo

Obrigado pelo interesse no cliente Roku!

- Abra uma issue para relatar bugs, incluindo **modelo do Roku, versão do Roku OS, versão da build e passos de reprodução**.
- Nunca inclua login, tokens de conta, PIN de perfil, códigos QR válidos, endereço de IP particular, playlists privadas ou dados pessoais em capturas/logs públicos.
- Para enviar alterações, crie uma branch, faça commits pequenos e envie um Pull Request com explicação e evidências de teste.
- Execute `python tools/check_source.py` e `python tools/package_roku.py` antes do PR.
- Testes no BrightScript Simulator não equivalem à validação num Roku real; informe claramente onde testou.
- Preserve os avisos GPL-3.0, autores e os créditos indicados em `THIRD_PARTY_NOTICES.md`.
- Não inclua imagens de filmes/séries, fontes de streaming ou dados com restrição de redistribuição sem os direitos necessários.
