# Contribuindo

Obrigado pelo interesse no NuvioTV-Roku!

1. Abra uma Issue com modelo do Roku, Roku OS, versão da build, comportamento esperado, comportamento observado e passos de reprodução.
2. Para alterações, crie uma branch e envie um Pull Request pequeno, descrevendo as modificações e como testou.
3. Nunca inclua tokens, cookies, QR Codes válidos, PINs, senhas, playlists privadas, endereços privados ou dados de terceiros em capturas, logs e código.
4. Preserve a licença GPL-3.0 e os créditos do código-base. Para artes, confirme permissões de distribuição.
5. Informe se testou em simulador, no Roku físico ou em ambos. A aprovação visual não implica homologação de playback, autenticação e desempenho.

Esta branch contém apenas a preparação documental; a importação do código-fonte ainda está pendente.
